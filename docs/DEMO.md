# Demonstration guide

## Prepare

Use a development-enabled iPhone with camera, location, microphone and speech permissions granted. Set required PPE for the demonstration. Configure the optional HTTPS assistant gateway and check its connectivity before presenting.

Use a controlled area for zone demonstrations. Create illustrative boundaries away from actual hazards. GPS can drift; do not present meter-level precision as established performance.

## Walkthrough

1. Show the initial dashboard and explain that it reflects stored events.
2. Start a live PPE check with one clearly visible worker. Show detected equipment and the compliance calculation for configured requirements.
3. Stop the scan and inspect the recorded result.
4. Draw a work zone and a restricted zone on Apple Maps.
5. Open the spatial view. Show direction, distance and the appropriate warning when a boundary transition is observed.
6. Open Voice Commands. Speak a visual question in Arabic, point out the live transcript, then press Stop. Show the single-frame analysis and spoken response.
7. Submit a hazard report. Open the operations dashboard and locate the saved record.
8. Create a task, complete its guided steps and refresh the optional record-based brief.

## Explain the boundaries

Local PPE operates without an internet connection. Cloud image analysis and generated speech require the assistant gateway. Local records remain available when connectivity fails. A stored hazard report is not a dispatched emergency request. Model predictions and spatial overlays require human review.

## Before judging

Check signing, camera preview, model loading, event persistence and gateway availability on the actual demonstration phone. Run automated checks from the README. Use real demonstration records; avoid replacing empty states with invented production metrics.
